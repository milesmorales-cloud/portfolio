# Portfolio Design System

## Product

Professional portfolio for Israel Japhary.

## Purpose

Showcase software projects, engineering skills, and progression toward
Cloud Engineering.

## Design thesis

Software → Systems → Cloud

The portfolio should feel like an engineer's workspace rather than a
generic developer template.

## Audience

- Recruiters
- Internship opportunities
- Developers
- Collaborators
- University/project reviewers

## Visual direction

Technical, modern, minimal, confident, and distinctive.

The visual language takes inspiration from software systems,
infrastructure, deployment pipelines, and engineering tools.

## Color

- Background: #0B0F14
- Surface: #111820
- Elevated surface: #17212B
- Primary text: #F2F5F7
- Muted text: #8D9AA6
- Accent: #6EE7B7

The accent color represents active systems, links, and important states.

## Typography

- Display: Space Grotesk
- Body: Inter
- Technical/data: JetBrains Mono

## Signature

A restrained live-system/infrastructure visualization connecting:

Software → Container → Cloud

This is the primary visual signature of the portfolio.

## Motion

Motion should communicate system activity and navigation.

Use subtle:
- entrance transitions
- hover states
- status indicators
- infrastructure-line animation

Respect `prefers-reduced-motion`.

## Layout

Desktop:
- generous horizontal spacing
- strong typography
- asymmetric visual balance
- clear content hierarchy

Mobile:
- single-column layout
- preserved hierarchy
- comfortable touch targets
- no horizontal overflow

## Accessibility

Target WCAG 2.2 AA.

Requirements:
- semantic HTML
- visible keyboard focus
- sufficient color contrast
- accessible interactive labels
- reduced-motion support
- responsive layout
- no information communicated by color alone

## Content principles

Be specific about what was built.

Prefer evidence over claims.

Project descriptions should communicate:
- what was built
- technologies used
- important engineering decisions
- deployment
- lessons learned

Avoid generic claims such as:
"Passionate developer"
"Tech enthusiast"
"Hard-working programmer"

## Engineering principles

The portfolio itself is an engineering project.

Planned capabilities:

- React
- TypeScript
- responsive UI
- accessibility
- Git/GitHub
- Docker
- CI/CD
- cloud deployment
