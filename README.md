## Development

### Requirements

* Node.js
* npm
* Git

### Clone

```bash
git clone https://github.com/milesmorales-cloud/portfolio.git
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

### Build for production

```bash
npm run build
```

### Run linting

```bash
npm run lint
```
